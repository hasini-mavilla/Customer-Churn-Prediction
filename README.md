# Customer Churn Prediction

## Project Overview
This Machine Learning project predicts whether a telecom customer is likely to leave the company (Churn) based on customer information and service usage.

## Dataset
- 7043 customer records
- Telecom customer dataset
- Target variable: Churn (Yes/No)

## Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest

## Project Workflow
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Data Preprocessing
4. Model Training
5. Model Evaluation
6. Model Comparison

## Results
- Logistic Regression – 82.04% Accuracy
- Decision Tree – 71.47% Accuracy
- Decision Tree (Max Depth 5) – 80.62% Accuracy
- Random Forest – 78.50% Accuracy

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Conclusion
Logistic Regression achieved the best accuracy among the models tested in this project. The project demonstrates a complete Machine Learning workflow for customer churn prediction.
